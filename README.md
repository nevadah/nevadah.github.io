# nevadah.github.io

Nevada Hamaker's personal website: experience, projects, and writing. Published at [https://nevadah.github.io](https://nevadah.github.io).

Built with [Astro](https://astro.build). `npm ci && npm run dev` to run it locally; pushing to `main` publishes it through GitHub Actions.

Content lives in `src/content/` as one file per role, project, or article; see `CLAUDE.md` for the fields.
