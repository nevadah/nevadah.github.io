My accomplishments in this role include:

- Architected, expanded, and maintained test automation framework and test case library for the Big Fish Games website, written in Python and built on Selenium, significantly improving test coverage.
- Expanded and maintained Java-based automation framework and test case library for the back-end services, significantly improving test coverage.
- Contributed directly to production web-service code and collaborated closely with developers. I progressively took on back-end development responsibilities that led to a formal transition to the Senior Software Engineer role.
- Designed and implemented a standalone microservice as part of a larger project, gaining hands-on experience with service design, integration, and deployment considerations.
- Implemented a utility written in C# which translated save game data for one of Big Fish’s mobile games to and from its compressed binary format to support customer service’s ability to update customers’ save data as needed.
- Managed branch operations and CI/CD releases in a continuous delivery environment.

**Technologies used include:** Python, Java, Spring Boot, Dropwizard, JavaScript, PHP, Selenium, Jenkins, Docker, Kafka, Kubernetes, Google Cloud Platform, Redis, Memcache, Git, SVN, Mercurial, JIRA, Confluence, Kibana, and more.
