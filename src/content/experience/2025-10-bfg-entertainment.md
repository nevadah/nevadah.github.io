The major project I worked on was the complete rebuild of the Big Fish Games website front end on Adobe PWA Studio, replacing the previous front end built on Adobe Experience Manager. The new React-based site cut costs substantially, improved performance, and allowed faster iteration on fixes and features.

My accomplishments during this project include:

- Replaced or extended many of the existing React components and implemented several new ones. For example, I implemented a new “Promotional Content Block” component that is used by the Marketing team to display banners or other promotional material. It can choose from several different content blocks to display based on conditions including whether the customer has made any purchases and whether the customer is a member of Game Club.
- Implemented the payment methods page, including support for Game Club membership payments, which required updating a Magento GraphQL resolver.
- Adapted existing GraphQL queries, implemented new ones, and extended the Magento back end with new resolvers for product and customer data to support custom front-end functionality.

During this project, AI coding tools (Claude Code in particular) became truly useful. They accelerated customization, new feature implementation, GraphQL integration, and styling updates for the new front end. They allowed us to release it to production ahead of schedule and quickly follow up with updates and fixes. I continued to learn where my own judgment was still important and when to push back or change course.

**Technologies used include:** Adobe PWA Studio, Magento, React, GraphQL, PHP, JavaScript, TypeScript, MySQL/MariaDB, Composer, Yarn, GitHub Actions, New Relic, Claude Code.
