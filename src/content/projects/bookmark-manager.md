---
title: Bookmark Manager
description: A browser extension for Chromium-based browsers and Firefox that organizes bookmarks with tags instead of folders, including hierarchical tags, and can tag them automatically with AI using your own API key. It works locally with no account, storing bookmarks in the browser or in a JSON file you can keep in a synced folder. An optional backend service for sync is in development.
repo: https://github.com/nevadah/bookmark-manager
tech: [TypeScript, React, Vite, WebExtensions (Manifest V3), Fastify, Prisma, PostgreSQL, Vitest]
order: 2
