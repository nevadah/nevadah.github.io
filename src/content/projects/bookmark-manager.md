title: Bookmark Manager
description: "A cross-browser extension for Chromium-based browsers and Firefox (Manifest V3) that organizes bookmarks with hierarchical tags instead of folders, with optional AI auto-tagging through pluggable providers (Anthropic, OpenAI, Azure OpenAI, and OpenRouter). Built in TypeScript and React. I wrote the code myself, with Claude guiding the process, reviewing my work, and acting as a design collaborator; design decisions and how they changed after real use are documented in the repo. It stores data locally, in a JSON file or browser storage, and it’s now my primary bookmark manager."
